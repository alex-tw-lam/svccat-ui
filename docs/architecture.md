# Responsibilities model — one file, one responsibility: a sentence, a boundary, a place in the dependency graph.

| File                                                                                    | Responsibility                                                                                                                                                                                                                                                                                                    | Must NOT                                                       |
| --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `manage.py` + `service_manager/{settings,urls,wsgi}.py` · `Dockerfile`/`pyproject.toml` | boot + packaging: env-driven settings, URL→view table, runserver/check/wsgi-gunicorn                                                                                                                                                                                                                              | hold logic                                                     |
| `core/views.py`                                                                         | every route — pick backend (kube/memory), validate, render; vendored-asset serving; OIDC (PKCE, exchange, JWT decode), tenant mapping, CR→record translation; the one big file                                                                                                                                    | touch Kubernetes outside `kube.py`; define the input contract  |
| `core/kube.py` + `core/memory.py`                                                       | the backend seam (same verbs: list/get/create/delete): kube = CR CRUD, namespaces, RBAC, secrets, DNS-slug names + `service-manager.io/*` annotation (connects in-cluster first, then the local kubeconfig context); memory = dev store (static catalog, per-tenant lists); backend-choice policy is the caller's | render, validate, know each other                              |
| `core/input_schema.py`                                                                  | the input contract (computed > plan > user, platform-pinned): schema tables, form schema, server validation, client mirror — source of truth for views/templates/app.js                                                                                                                                           | know HTTP, Kubernetes, templates                               |
| `core/middleware.py`                                                                    | request gate: session check, tenant resolution (local admin sees every active namespace), no-store, visible 500s (delegates the error page to `views._error_page`)                                                                                                                                                | render pages, touch the catalog                                |
| `core/templates/*` · `core/public/{app.js,app.css}` · `core/templatetags/sm_tags.py`    | presentation: one file per page/fragment rendering view dicts; the Alpine contract mirror + css overlay; the one filter `badge_cls`                                                                                                                                                                               | compute, query, validate, become an authority                  |
| `tests/`                                                                                | the regression suite (94 tests): each module maps to one core unit (store, backend, contract, gate+pages, records/tenancy); mocks the `kube.kube` handle, drives the rest through the URL table black-box                                                                                                         | import `service_manager`, patch core internals beyond the seam |

```
urls ─► views ─► { kube ─► k8s client · memory · input_schema · requests (token exchange) }
middleware ─► kube (admin namespace list) · middleware ─► views (error page, deferred import)
templates ◄─ views (read request.session for display, sm_tags filter only)
app.js ◄─ views._contract_json (input_schema.drawer_contract rendered as JSON into a script tag)
tests ─► core (black-box via urls; the kube.kube handle is the only seam mock)
Only views imports every core module; urls and middleware (deferred) import views;
input_schema imports none; no cycles.
```

- All data flows through the `kube.py`/`memory.py` seam — `kubernetes`/`CustomObjectsApi` appears nowhere else; the `service-manager.io/*` naming policy lives in `kube.py` + the views record mappers only.
- Input validation lives in `input_schema.py` (schema layer, mirrored in `app.js`); form-level checks (required fields, the 60-char name cap, raw-JSON parse) live in `views._form_params`.
- Session keys are written in `views.py` auth handlers only; read in `middleware.py`, `_page_ctx`, and (display-only) `layout.html`.
- Templates receive plain dicts; an `if` smarter than display-or-hide means logic leaked into presentation.

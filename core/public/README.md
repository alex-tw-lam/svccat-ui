# core/public/ — first-party assets + vendored-library slots

Served by WhiteNoise (`whitenoise.middleware.WhiteNoiseMiddleware` — see `service_manager/settings.py`): the
directory is a `STATICFILES_DIRS` entry at `STATIC_URL = "/"`, so files land at their flat names (wired in
`core/templates/core/layout.html`). No build step. After dropping vendored files in, run
`python manage.py collectstatic --noinput` so WhiteNoise picks them up (and precompresses `.gz` variants —
gunicorn has no compress layer). Absent files fall through to a clean 404.

| URL served                | File in this directory           | Shipped in repo?                                 |
| ------------------------- | -------------------------------- | ------------------------------------------------ |
| `/app.js` `/app.css`      | `app.js` `app.css`               | yes (first-party: Alpine logic + overlay styles) |
| `/htmx.min.js`            | `htmx.min.js`                    | **no — drop in**                                 |
| `/alpine.min.js`          | `alpine.min.js`                  | **no — drop in**                                 |
| `/htmx-preload.min.js`    | `htmx-preload.min.js`            | **no — drop in**                                 |
| `/alpine-collapse.min.js` | `alpine-collapse.min.js`         | **no — drop in**                                 |
| `/alpine-focus.min.js`    | `alpine-focus.min.js`            | **no — drop in**                                 |
| `/daisyui.css`            | `daisyui.css`                    | **no — drop in**                                 |

## Files the operator must drop in (exact names; `.gitignore` excludes them)

1. **`htmx.min.js`** — htmx **2.0.4** (the version this app was built and tested against).
2. **`alpine.min.js`** — Alpine.js **3.14.9** core build (`alpinejs/dist/cdn.min.js`; rename).
3. **`htmx-preload.min.js`** — htmx **preload** extension (`htmx-ext-preload@2`; self-registers; elements
   opt in with a `preload` attribute).
4. **`alpine-collapse.min.js`** — Alpine **collapse** plugin (`@alpinejs/collapse@3.14.9/dist/cdn.min.js`;
   provides the `x-collapse` directive). Load BEFORE `alpine.min.js`.
5. **`alpine-focus.min.js`** — Alpine **focus** plugin (`@alpinejs/focus@3.14.9/dist/cdn.min.js`; provides
   `x-trap`). Load BEFORE `alpine.min.js`.
6. **`daisyui.css`** — DaisyUI **4.12.24** prebuilt **full** css (`daisyui/dist/full.css`; rename). Do NOT
   substitute a tailwind-built subset — the templates use components across the whole prebuilt file.
   (`.gz` variants are generated by `collectstatic`; a hand-made `daisyui.css.gz` is no longer needed.)

Quick copy-paste:

```sh
cd core/public && curl -fsSLo htmx.min.js https://unpkg.com/htmx.org@2.0.4/dist/htmx.min.js && curl -fsSLo alpine.min.js https://unpkg.com/alpinejs@3.14.9/dist/cdn.min.js && curl -fsSLo htmx-preload.min.js https://cdn.jsdelivr.net/npm/htmx-ext-preload@2/dist/preload.min.js && curl -fsSLo alpine-collapse.min.js https://cdn.jsdelivr.net/npm/@alpinejs/collapse@3.14.9/dist/cdn.min.js && curl -fsSLo alpine-focus.min.js https://cdn.jsdelivr.net/npm/@alpinejs/focus@3.14.9/dist/cdn.min.js && curl -fsSLo daisyui.css https://unpkg.com/daisyui@4.12.24/dist/full.css
```
